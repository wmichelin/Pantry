# Legacy scraper extraction oracle

`scraper-extraction.json` is a shared, language-neutral extraction oracle. Its
expected objects were generated on 2026-09-08 from the unchanged
`supabase/functions/scrape-recipe/index.ts` implementation of
`scrapeRecipeUrl`, not handwritten or generated by the Go implementation.

Pinned source SHA-256:
`0c388826d481b2ff03550eb22dc80a7529070cf97853278fdc183569dbd171aa`.

The generation runtime was `oven/bun:1.3.14` with `cheerio@1.0.0`, matching the
legacy extractor's Cheerio version. Bun transpiled the TypeScript. Only import
declarations were removed so Cheerio could be injected; function bodies were
unchanged. A no-op `Deno.serve` prevented listener registration, and a fixture-only
fetch stub returned synthetic HTML while rejecting any unexpected URL. No live
website, database, account, or deployed application was accessed.

## Coverage and limits

The cases cover first-recipe selection, JSON-LD precedence over article/Open
Graph fallbacks, optional-field presence (including empty image and zero
servings), duplicate JSON keys, nested instructions, tag ordering, JavaScript
whitespace/case behavior, UTF-16 text lengths, numeric exponent inputs, decimal
and nested entities, article-specific decoding, and Open Graph defaults.

Missing optional properties are intentional; consumers must distinguish them
from present empty strings or zeroes. Array order and empty arrays are also
significant. This fixture demonstrates those deterministic extraction behaviors,
not arbitrary website compatibility or parity of fetching, authentication,
Pinterest discovery, SSRF controls, rate limits, or browser interactions. Lone
UTF-16 surrogates cannot be represented directly in Go strings; the separately
documented UTF-8-boundary normalization is covered by focused Go tests, not
claimed as byte-identical legacy JSON here.

## Reproduction

Run in a disposable `oven/bun:1.3.14` container with this repository mounted at
`/app` and working directory `/tmp`. Install only
`bun add --cwd /tmp cheerio@1.0.0` in that ephemeral container, then execute the
following with `bun -e`. The final `ORACLE_JSON:` output is the fixture; review
changes before replacing it. Do not edit expected values to make Go tests pass.

```javascript
const {load} = require("/tmp/node_modules/cheerio");
const {createHash} = require("node:crypto");
const source = await Bun.file("/app/supabase/functions/scrape-recipe/index.ts").text();
const fixture = await Bun.file("/app/contracts/fixtures/scraper-extraction.json").json();
fixture.provenance.source_sha256 = createHash("sha256").update(source).digest("hex");
const compiled = new Bun.Transpiler({loader:"ts"}).transformSync(source.replace(/^import .*;\r?\n/gm, ""));
for (const entry of fixture.cases) {
 const fixtureFetch = async (url, options) => {
  if (url !== entry.source_url) throw new Error("Unexpected legacy fixture fetch");
  return {ok:true,status:200,text:async()=>entry.html};
 };
 const run = new Function("load", "Deno", "fetch", compiled + "\nreturn scrapeRecipeUrl;")(load,{serve(){}},fixtureFetch);
 entry.expected = await run(entry.source_url, entry.source_type);
}
console.log("ORACLE_JSON:"+JSON.stringify(fixture,null,2));
```

Consume without Bun, dependency installation, network fetches, or database access:

```sh
docker run --rm \
  -v /tmp/pantry-full-parity:/app \
  -v pantry-go-module-cache:/go/pkg/mod \
  -v pantry-go-build-cache:/root/.cache/go-build \
  -w /app golang:1.24.11-bookworm \
  go test ./internal/scraper -run TestLegacyExtractionFixture -count=1
```

The Go consumer verifies the pinned legacy source hash before comparing every
field. A deliberate legacy baseline change therefore requires regenerating and
reviewing the fixture and its provenance together.
